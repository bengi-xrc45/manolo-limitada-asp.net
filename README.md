# Sistema de Gestión de Contactos - Manolo Limitada

Proyecto desarrollado en ASP.NET WebForms con C#, SQL Server y Bootstrap.

## Funcionalidades
- Login administrativo (usuario: admin contraseña: 12345)
- CRUD de contactos (crear, buscar, actualizar, eliminar)
- Búsqueda por cédula y apellido
- Edad calculada automáticamente
- Validaciones de datos

## Tecnologías
- ASP.NET WebForms 
- C#
- SQL Server LocalDB (La q nos ofrece Visual)
- Bootstrap

## Estructura del proyecto
- Models: entidades del sistema
- Services: lógica de negocio
- Data: conexión a base de datos
- WebForms: interfaz de usuario

## Ejecución
1. Abrir solución en Visual Studio
2. Restaurar base de datos (ManoloDB.mdf)
3. Ejecutar Login.aspx como página principal
